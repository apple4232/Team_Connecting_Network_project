# 실제 Solar 반복 진단 평가

2026년 11월 24일 `solar-pro4`로 수행한 반복 평가와 새 관측 자료 검증입니다.

| 경로 | 내용 | 진단·근거 통과 |
|---|---|---:|
| `input` | 반복 평가에 공통 사용한 네 사례의 관측 로그와 평가용 메타데이터 | 해당 없음 |
| `before/round-01` | 기존 형식, 11시 41분 41초 시작 | 3/4 |
| `before/round-02` | 기존 형식, 11시 41분 50초 시작 | 4/4 |
| `before/round-03` | 기존 형식, 11시 41분 57초 시작 | 4/4 |
| `after/round-01` | 중단·완료 관측 필드 추가, 11시 45분 51초 시작 | 4/4 |
| `after/round-02` | 중단·완료 관측 필드 추가, 11시 46분 00초 시작 | 4/4 |
| `after/round-03` | 중단·완료 관측 필드 추가, 11시 46분 13초 시작 | 4/4 |
| `fresh` | 11시 47분에 새로 생성한 네 사례, 실제 전략 적용 및 진단 | 4/4 |

시각은 한국 표준시입니다. 각 평가 폴더의 `comparison.csv`는 해당 요청들의 비교표입니다. 실행 ID 폴더에는 실제 요청 `request.json`, 실제 응답 `response_raw.json`, 채점 결과 `solar.json`을 보관했습니다. 새 실행에는 `solar_demo_summary.json`과 실제 전략 요청·응답을 기록한 클라이언트 로그도 있습니다. 테스트용 파일 바이너리는 포함하지 않았습니다.

반복 평가 입력의 `run_meta.json`은 팀 채점용 정답과 복구 결과를 포함하며, 실제 모델 입력은 저장된 `request.json`으로 확인할 수 있습니다. 모든 API 키는 인증 헤더로만 사용합니다. 이번 평가에서는 패킷 캡처를 요청하지 않았습니다.

변경 후에는 `solar_observations_correct`를 추가로 기록합니다. 기존 진단 정답과 근거 지지 항목은 같은 기준으로 유지했습니다. 같은 네 자료를 반복 호출한 결과이므로 다양한 장애 환경에 대한 일반 성능 평가는 추가 실험이 필요합니다.
